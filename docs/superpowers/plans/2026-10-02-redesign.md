# Redizajn interfejsa — plan izrade

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Zajednički miran vizuelni sistem i nov raspored za web i iPhone, bez promene pravila aplikacije.

**Architecture:** Stanje limita računa `packages/domain`. Web zadržava postojeće nazive CSS klasa i menja im vrednosti, pa forme i podešavanja dobijaju nov izgled bez prepisivanja; menjaju se samo okvir strane i mesečni pregled. iPhone dobija `theme.ts` i male komponente, pa ekrani koriste iste vrednosti.

**Tech Stack:** Next.js 16, `next/font/google` (Onest), Expo Router 57 (Tabs), React Native.

## Global Constraints

- Boje, tipografija i oblik tačno iz `docs/superpowers/specs/2026-10-02-redesign-design.md`.
- Prag crtice i boje: `spent*10 >= limit*8` je „blizu“, `spent >= limit` je „preko“.
- Tekst interfejsa ostaje na srpskom latinici; uloge i API pozivi se ne menjaju.
- Bez novih biblioteka komponenti (bez Tailwind-a, shadcn-a, NativeWind-a).
